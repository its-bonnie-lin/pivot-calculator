# 三關價計算器 📈

基於費波那契（Fibonacci）1.382 係數，計算股票或指數的上界壓力、中軸均衡、下界支撐價位的簡易工具。

🔗 **[線上瀏覽](https://its-bonnie-lin.github.io/pivot-calculator/index.html)**

## 什麼是三關價？

三關價以前一交易日的高低點為基礎，延伸出合理的價格區間，常用於輔助判斷隔日的支撐與壓力位置。

| 關卡 | 公式 | 說明 |
|------|------|------|
| 上界 | `低點 + (高點 - 低點) × 1.382` | 壓力位 |
| 中軸 | `(高點 + 低點) ÷ 2` | 均衡點 |
| 下界 | `高點 - (高點 - 低點) × 1.382` | 支撐位 |

> 1.382 = 1 + 0.382，為費波那契黃金比例衍生的關鍵係數。


### 本地使用（HTML 版）

直接下載 `index.html`，用瀏覽器開啟即可，**不需要安裝任何套件**。

```
下載 index.html → 雙擊開啟 → 輸入高低點 → 自動計算
```

## 範例

| 輸入 | 數值 |
|------|------|
| 最高價 | 68 |
| 最低價 | 61.8 |
| 落差 | 6.2 |

| 結果 | 數值 |
|------|------|
| 上界（壓力） | 70.37 |
| 中軸（均衡） | 64.90 |
| 下界（支撐） | 59.43 |
